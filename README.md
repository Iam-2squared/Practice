# Practice

日本株の仮想売買を練習する、シンプルなWebアプリ。

- 初期資金100,000円。現物のみ、練習用に1株単位。
- 下部3タブ：資産／取引／履歴・アカウント。
- メール登録なし、専用パスワードのみでログイン。
- 実際の株式注文・入出金・証券口座連携は一切ありません。
